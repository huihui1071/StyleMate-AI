# StyleMate AI

StyleMate AI 是一个面向多品牌时尚零售场景的 AI 导购与会员服务系统。它将顾客的自然语言需求转化为可执行的商品约束，通过结构化检索、搭配规则与会员权益引擎，完成选款、成套搭配和订阅服务，并在库存、交易或售后场景安全转交人工。

区别于只生成文本建议的聊天机器人，StyleMate AI 的每个推荐都能回溯到商品字段、会员偏好和业务规则。硬条件不会被模型擅自放宽，未知信息不会被补造。

## 业务问题

时尚零售导购同时面对三类复杂性：顾客使用口语表达模糊需求，商品属性与搭配关系分散在不同数据中，会员权益又有严格的门槛和触发时机。纯对话模型可以给出听起来合理的答案，却难以保证商品真实、筛选准确和权益合规。

StyleMate AI 将这三类问题拆成可验证的决策链：

```text
顾客需求
  → 意图与约束解析
  → 商品硬筛选
  → 场景与会员偏好重排
  → 搭配或会员规则执行
  → 事实校验
  → 推荐结果或人工接管
```

## 能力

- 智能导购：按虚构品牌、品类、颜色、版型、材质、场景和预算组合筛选。
- 搭配顾问：围绕指定单品或场景生成整套搭配，并解释颜色、材质与廓形关系。
- 会员顾问：读取已授权的虚构会员上下文，处理积分、订阅节点、兑换值和 BOX+ 介绍时机。
- 安全接管：面对实时库存、支付、退款或资料缺失时生成结构化人工摘要。
- 工程评测：自动测试硬条件、推荐数量、个性化差异和敏感信息门禁。

## 关键设计选择

- **结构化筛选先于语义推荐**：品牌、品类、颜色、版型、材质和预算先由确定性逻辑过滤，模型不能把不满足条件的商品混入结果。
- **业务规则独立于提示词**：订阅门槛、节点礼、兑换提醒和续订规则保存在版本化配置中，可单独测试和更新。
- **产品官网与完整工作台互通**：官网通过真实可操作的精简 Demo 介绍产品，完整工作台承接连续选款、搭配和会员服务。
- **推荐依据按需展开**：结果优先展示商品和搭配结论，用户可以在当前结果内展开筛选依据和结构化商品详情。
- **人工接管是正常路径**：实时库存、支付、退款、订阅变更和资料冲突不会由系统假装处理，而是生成结构化接管摘要。
- **公开数据默认匿名**：商品名称、会员、品牌和编号均为匿名演示内容；商品图片来自项目资料并本地化处理，隐私扫描会阻止源文件、源链接和可疑编号进入仓库。

## 本地运行

### 1. 后端

```bash
cd StyleMate-AI
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn apps.api.main:app --reload --port 8000
```

### 2. 前端

```bash
cd StyleMate-AI
npm install
npm run dev:web
```

访问 `http://localhost:5173` 查看产品官网，进入 `http://localhost:5173/demo` 使用完整导购工作台。

也可以使用 Docker 一次启动：

```bash
docker compose up --build
```

## 在线部署

仓库根目录提供单服务 `Dockerfile` 和 `render.yaml`，可作为 Render Blueprint 直接部署。部署时会先构建 React 前端，再由 FastAPI 同域提供官网、Demo、商品图片和推荐接口。

部署后的健康检查地址为 `/api/health`。免费实例在一段时间没有访问后可能休眠，首次打开需要等待服务唤醒。

## 验证

```bash
npm run privacy
npm run test:api
npm run test:web
npm run build:web
```

## 数据与隐私

仓库只包含匿名化的演示商品、会员与业务规则。品牌、SKU、商品名称和会员身份均为演示内容；商品图片来自项目资料，经人工匹配后以匿名文件名保存，不保留原始链接与文件元数据。原始业务文件、真实企业名、真实品牌名、源 SKU、内部域名及逐行映射不会进入仓库。

## 当前边界

本项目不连接真实库存、支付、CRM、客服或消息系统，也不执行真实开通、续订、退货或积分兑换。价格为演示标准价，人工接管为模拟状态。
